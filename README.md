## 贪吃蛇吃贡献图

这条蛇每天自动重新生成，把过去一年的贡献格子全部吃掉：

  <source media="(prefers-color-scheme: dark)" srcset="https://raw.githubusercontent.com/zhouyuanxinand/zhouyuanxinand/output/github-snake-dark.svg">
  <img alt="snake eating the contribution graph" src="https://raw.githubusercontent.com/zhouyuanxinand/zhouyuanxinand/output/github-snake.svg">

由 [`scripts/generate-snake.js`](scripts/generate-snake.js)（零依赖 Node 脚本）生成，
[`.github/workflows/snake.yml`](.github/workflows/snake.yml) 每天定时运行并把结果发布到
[`output`](https://github.com/zhouyuanxinand/zhouyuanxinand/tree/output) 分支。
视觉效果灵感来自 [Platane/snk](https://github.com/Platane/snk)。
